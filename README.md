# IA-A_estrela

Trabalho acadêmico de Inteligência Artificial. 
Software executável em python que utiliza o algoritmo A* para resolver o problema de um jogo baseado em Exponential Idle, expondo a heurística e os caminhos escolhidos.

Academic Artificial Intelligence project. Executable Python software that uses the A* algorithm to solve a game-like problem inspired by Exponential Idle, displaying the heuristic and the selected solution paths.
